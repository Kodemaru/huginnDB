# ADR / Gotchas index

This directory holds one Architecture Decision Record (ADR) per "hard-earned gotcha" from `CLAUDE.md`. Each file documents a specific, non-obvious architectural decision or trap in HuginnDB's codebase — file names, function names, issue references and all the original detail preserved.

This is internal documentation for AI coding agents (Claude Code and similar) and contributors doing fixes on this repo. It is deliberately kept **outside `docs/`**: `docs/*.md` is auto-indexed into the app's own in-app Documentation viewer (see [gotcha #50](gotcha-050-docs-viewer-markdown-derived-navigation.md) — `src/lib/appInfo/docOutline.ts` derives that viewer's navigation from the markdown files it finds there), and these ADRs are not meant to appear to end users.

Before touching code in an area with history (Zustand, Monaco, tab_state, MySQL/MongoDB decoding, dockview, environments, MCP, ...), check the index below and read the relevant ADR in full — the one-line summary is not a substitute.
